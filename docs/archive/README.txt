COBRA Podium Gallery — one photo upload link
=============================================

The gallery has one Upload podium photo link beside the selected event heading. There are no upload links in individual final cards. The upload form still lets the visitor choose the event, class and final.

To update GitHub, extract this ZIP. At the TOP LEVEL of your cobra-liverc-stats repository choose Add file > Upload files and drag the extracted public folder onto the upload area. Before committing verify the paths are public/podiums/index.html and public/assets/podiums.js. Wait for the publish workflow to succeed, then reload the gallery (Ctrl+F5 if your browser shows the older page).

No Google Apps Script redeployment is required. Do not upload the README to GitHub.
