# Historical exports

The folders here contain older website snapshots and superseded files. They are not published by GitHub Pages and must not be used as the current source when making edits.

Use the [main README](../README.md) and active `public/` folder. The [legacy-site-files](legacy-site-files/README.md) folder preserves duplicate or unused files removed from the published tree during cleanup. Earlier update-package instructions are in the [documentation archive](../docs/archive/README.md).
