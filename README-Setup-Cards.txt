COBRA Driver Setup tile update
==============================

GitHub:
1. Extract COBRA-Setup-Card-Borders.zip.
2. Open your GitHub repository's EXISTING public/ folder.
3. Drag the extracted assets/ and setups/ folders into public/. If GitHub asks, commit the upload. Do not add another public/ folder.
4. The bordered setup cards display in two columns on wider screens and one column on phones. The upload form and existing setups are unchanged.

Private Site Manager:
If you use the COBRA Site Manager export to update the site, extract COBRA-Setup-Manager-Patch.zip over your EXISTING manager folder. The patch contains public/assets/setup-cards.css, public/setups/index.html and admin/avatar_store.py so future manager exports include the new style.

No Google Apps Script change or new deployment is needed.
